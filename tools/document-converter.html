auto_awesomePaperFlow

PaperFlow converts documents between formats entirely in your browser. Nothing is uploaded, nothing leaves your device.

Reads: TXT, Markdown, HTML, CSV, JSON, DOCX, XLSX, PPTX, EPUB, PDF.

Writes:

  • Word (.docx) — headings, lists, tables, images, headers & footers
  • PDF — vector text, real tables, high-res raster fallback for non-Latin scripts
  • Excel (.xlsx) — each detected table becomes a sheet
  • PowerPoint (.pptx) — one slide per heading
  • HTML, Markdown, plain text, CSV, and a JSON IR dump

HTML input: By default, HTML files are parsed and converted to readable content. Choose "Keep as source code" in the controls to embed the raw HTML instead.

Note: Complex PDFs (multi-column layouts, scanned pages, heavily formatted documents) may convert imperfectly. Hindi and other non-Latin scripts in PDF output render as high-resolution raster text — visually correct but not selectable.
