palette Color Studio

A complete color workstation that never touches the network.

What you can do

  • Native picker — open your operating system's color dialog.
  • Eyedropper — sample any pixel on your screen (Chromium browsers).
  • Image picker — drop, browse or paste an image, then hover for a live magnifier and click any pixel.
  • Dominant colors — automatically extract the most-used colors from an image.
  • Palette generator — analogous, complementary, split, triadic, tetradic, mono, shades and tints.
  • Contrast check — live WCAG ratio against white and black.
  • Export — copy CSS variables, JSON, or download an SVG palette sheet.

Privacy

Everything runs in this page. Images are decoded locally with the FileReader API and drawn to a canvas — nothing is uploaded, stored remotely, or tracked. Saved palettes live only in this browser's local storage.

Shortcuts

  • Ctrl + V — paste an image from the clipboard.
  • Esc — close this dialog.
