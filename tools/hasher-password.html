About CryptSilo

Everything runs on your device. No text, file, hash or password is ever transmitted, stored or logged. Open your browser's network panel — you'll see nothing.

Hashing

  • SHA-1, SHA-256, SHA-384 and SHA-512 use the browser's native Web Crypto engine.
  • MD5 is implemented in JavaScript for compatibility. It is cryptographically broken — use it only for checksums and legacy interop, never for security.
  • Text is encoded as UTF-8 before hashing, so the byte count shown is the true input length.

Passwords

  • Randomness comes from crypto.getRandomValues(), the same CSPRNG your browser uses for TLS.
  • The entropy figure assumes an attacker knows your exact settings — it measures the search space, nothing else.
  • Passphrases draw from a built-in —-word list. Long and memorable beats short and cryptic.

Tip: for a master password, aim for 80+ bits. For everyday accounts, 60+ is plenty.
