    About Image Converter

    Converts images between twelve formats entirely inside your browser. No file ever touches a server — there is no network code in this page at all.

    • PNG — lossless, keeps transparency
    • JPG — small, lossy, no transparency
    • WEBP — modern, small, keeps transparency
    • GIF — 256 colours, 1-bit transparency
    • BMP — uncompressed bitmap
    • TIFF — uncompressed, print friendly
    • ICO — multi-size favicon (16→256 px)
    • SVG — your raster image wrapped in a scalable SVG
    • TGA — Targa, uncompressed 32-bit BGRA. Popular in game dev and 3D textures
    • QOI — Quite OK Image, modern lossless format with an extremely fast encoder
    • PPM — Portable Pixmap (Netpbm), simple uncompressed RGB used across Unix
    • XBM — X BitMap, monochrome text-based format embedded in C source
    schedule AVIF — coming soon. Every browser can display AVIF, but none can encode it via the built-in Canvas API. Adding a WASM encoder is planned for a future update.

    Tip: you can also paste an image with Ctrl + V, or drop files anywhere on the page.
